# Mobile app UI kit (concept)

The app doesn't exist yet — this kit is the design target: a Duolingo-style section path (Home), the teach-back lesson flow (Lesson), and a celebration result (Result), framed in iOS devices.

Files: `index.html` (three framed screens), `screens.jsx`, `ios-frame.jsx` (device frame starter).

Rules carried over: canonical state names and honest grades; 44px+ hit targets; soft coral for errors; locked path nodes are gray with a lock, never red.
