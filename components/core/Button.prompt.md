The primary action control: restrained rounded button with a hard darker bottom edge that physically presses down 3px on click.

```jsx
<Button variant="primary" size="lg" onClick={grade}>Grade my teach-back</Button>
<Button variant="accent" ghost>Skip for now</Button>
```

Variants: primary (clover — default and success actions), accent (tangerine), info (splash), danger (soft coral), star (sunny gold). `variant="ghost"` or `ghost` renders the outline form. Sizes sm/md/lg; all meet the 44px tap minimum. Buttons use Sora, sentence case.
