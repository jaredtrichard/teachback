The primary action control: chunky rounded button with a hard darker bottom edge that physically presses down 4px on click.

```jsx
<Button variant="primary" size="lg" onClick={grade}>Grade my teach-back</Button>
<Button variant="accent" ghost>Skip for now</Button>
```

Variants: primary (clover — default & success actions), accent (tangerine — streak/energy), info (splash), danger (soft coral — destructive, never harsh red), star (sunny gold, dark text). `ghost` renders the outline form. Sizes sm/md/lg; all meet 44px tap minimum. Buttons use Baloo 2, sentence case.
